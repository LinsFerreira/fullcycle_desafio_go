## Estrutura Sugerida do Projeto

├── Dockerfile       # Configuração da imagem

├── main.go          # Código fonte da aplicação em Go

├── go.mod           # Gerenciador de dependências (se necessário)

└── README.md        # Instruções e link da imagem

## Entregável

Link do Repositório: O link para o repositório público (GitHub, GitLab, etc.) contendo o código-fonte e o Dockerfile.

README com Instruções: O arquivo README.md é o guia para o avaliador e deve obrigatoriamente conter:

## O link para baixar a imagem no Docker Hub
docker pull walterlinsferreira/fullcycle-rocks:latest

## O comando exato para baixar e rodar a imagem
docker run walterlinsferreira/fullcycle-rocks:latest
